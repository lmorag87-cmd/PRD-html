# 停车场找车 · HMI 信息架构（UC-FIND-1 / §7.5）



> 与飞书 PRD 对齐：**仅驻车后（P 挡车位记录窗口）静态拍照**，写入 **media_index**；**离线可用**（车机本地落盘 → 蓝牙/数字钥匙推 App 本地库，见 §7.5.3）；**不录制**找车长视频、不写入影像记录循环/紧急条目；**不在进场/入库过程中采集找车照片**。



## 能力范围



| 有 | 无 |

|----|-----|

| **驻车段**：P 挡环视/周视/底盘静态拍照 | 入库段 / 进场过程找车照片 |

| 找车专用连续视频 / 1 分钟录像 | 记忆泊车路径回放 |

| 车机本地素材索引；挪车后再拍**覆盖**上一版（驻车素材+记录点） | 停车过程视频写入影像记录相册 |
| **离线找车**：App 本地库 + 蓝牙短距闪灯鸣笛；车云为增强 | 找车必须实时联网 |

| 车机/App 地图记录点；展示驻车记录缩略图 | 车机端步行导航 UI |

| 第三方地图导航至记录点、弱网快照 | 默认识别旁车车牌 |



## 车机 IVI（1920×1080）



| 屏 ID | 名称 | 要点 |

|-------|------|------|

| **SCR-FIND-00** | 驻车 · 车位记录窗口 | P 挡 + 车速 0；环视/周视/底盘静态照；**写入车机本地** |

| **SCR-FIND-01** | 确认车位 | 预览驻车素材；OCR 预填；覆盖式重录；同步车云 |



**主流程**：00（驻车窗口）→ 01 确认 → **手机 App**（PG-FIND-01/02 等）。



**采集覆盖**：挪车后再采集时，**驻车素材与记录点一并覆盖**；车机/App 仅保留最新一版。



## 手机 App（390×844）



| 屏 ID | 名称 | 要点 |

|-------|------|------|

| **PG-FIND-00** | 推送落地 | 深链进找车 |

| **PG-FIND-01** | 停车会话卡 | 地图 + 距离 + 驻车照片 + POI/OCR；**App 本地缓存** |

| **PG-FIND-02** | 步行找车 | 指引 + 第三方导航 + **蓝牙闪灯鸣笛** |

| **PG-FIND-03** | 无网找车/分享 | **本地库优先**；闪灯鸣笛；有网时刷新增强 |

| **PG-FIND-04** | 补拍补录 | 离车后补拍 → `app_supplement` 分组；不计入 N_parking；车端重录后拉最新 session_version |



**分工**：**车机**负责驻车采集与确认（本地落盘）；**App** 负责离车后查看、导航、补拍、**离线找车**（蓝牙同步本地库）。

**PRD §7.5.3 离线链路**：驻车数据车端本地 → 离车前后蓝牙/数字钥匙推 App 本地库 → 找车读本地 + 近场闪灯鸣笛；车云非前置。



**PRD 增补（7.5.1 / 7.5.2）**：仅驻车段采集、泊车方式照片窗口表、张数上限与 0 张降级、车端重录整包替换 vs App 补拍；不提供记忆路径回放。
