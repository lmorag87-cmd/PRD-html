# 停车场找车 · HMI 信息架构（UC-FIND-1 / §6.4）

> 与飞书 PRD 对齐：**静态拍照记录车位 + 地图记录点找车**；**不录制**停车过程视频。

## 能力范围

| 有 | 无 |
|----|-----|
| P 挡驻车自动/手动拍照（环视/周视/底盘）；挪车后再拍**覆盖**上一版 | 记忆泊车路径回放 |
| 车机/App 地图记录点、环境照片 | 停车过程视频/连续录像 |
| 第三方地图导航至记录点、弱网快照 | App 主路径环视采集（仅补拍） |

## 车机 IVI（1920×1080）

| 屏 ID | 名称 | 要点 |
|-------|------|------|
| **SCR-FIND-00** | 车位记录 | P 挡采集环视/底盘静态照片 |
| **SCR-FIND-01** | 确认车位 | 预览照片、车位号、重新记录 |
| **SCR-FIND-02** | 找车主页 | 地图图钉 + 车位卡 + 入口 |
| **SCR-FIND-04** | 环境照片 | 环视四向 + 车底环境一张，可补拍 |
| **SCR-FIND-05** | 弱网离线 | 上次快照 + 楼层/车位号 |

**主流程**：00 采集 → 01 确认 → 02 找车 ↔ 04 照片；弱网进 05。**无**轨迹回放页。

**采集覆盖**：同一会话内，挪车后再次满足 P 挡零速采集时，新素材与记录点**覆盖**上一版；车机/App 仅保留最新一版（重录同逻辑）。

## 手机 App（390×844）

| 屏 ID | 名称 | 要点 |
|-------|------|------|
| **PG-FIND-00** | 推送落地 | 深链进找车 |
| **PG-FIND-01** | 停车会话卡 | 地图 + 距离 + 照片 |
| **PG-FIND-02** | 步行找车 | 指引 + 第三方导航 |
| **PG-FIND-03** | 弱网/分享 | 静态卡、分享粒度 |
| **PG-FIND-04** | 补拍补录 | 离车后补拍 |

**分工**：采集主路径在车机；App 查看记录点、导航、补拍。
