# 停车场找车 · HMI 信息架构（UC-FIND-1 / §6.4）

> 与飞书 PRD 对齐：**入库段稀疏关键帧 + P 挡静态拍照**，合并为同一套 **media_index**；**不录制**找车长视频、不写入影像记录循环/紧急条目。

## 能力范围

| 有 | 无 |
|----|-----|
| **入库段**（P 挡前）：低速稀疏关键帧 + POI 识别（电梯厅/分区牌/柱子等） | 找车专用连续视频 / 1 分钟录像 |
| **驻车段**：P 挡环视/周视/底盘静态拍照 | 记忆泊车路径回放 |
| 车机本地素材索引；挪车后再拍**覆盖**上一版（含入库段+驻车） | 停车过程视频写入影像记录相册 |
| 车机/App 地图记录点；分组展示「入库段锚点」「驻车记录」 | 车机端步行导航 UI |
| 第三方地图导航至记录点、弱网快照 | 默认识别旁车车牌 |

## 车机 IVI（1920×1080）

| 屏 ID | 名称 | 要点 |
|-------|------|------|
| **SCR-FIND-00a** | 入库段环境锚点 | 低速接近车位；稀疏关键帧 + POI 标注；后台写入 media_index |
| **SCR-FIND-00** | 驻车 · 车位记录窗口 | P 挡 + 车速 0；环视/周视/底盘静态照 |
| **SCR-FIND-01** | 确认车位 | 分组预览入库段+驻车；OCR 预填；覆盖式重录；同步车云 |

**主流程**：00a（入库段，可与行驶重叠）→ 00（驻车窗口）→ 01 确认 → **手机 App**（PG-FIND-01/02 等）。

**采集覆盖**：挪车后再采集时，**入库段关键帧与驻车素材、记录点一并覆盖**；车机/App 仅保留最新一版。

## 手机 App（390×844）

| 屏 ID | 名称 | 要点 |
|-------|------|------|
| **PG-FIND-00** | 推送落地 | 深链进找车 |
| **PG-FIND-01** | 停车会话卡 | 地图 + 距离 + **入库段/驻车**分组照片 + POI 摘要 |
| **PG-FIND-02** | 步行找车 | 指引 + 第三方导航 |
| **PG-FIND-03** | 弱网/分享 | 静态卡、分享粒度 |
| **PG-FIND-04** | 补拍补录 | 离车后补拍（追加，不删车端已入库帧） |

**分工**：**车机**负责两阶段采集与确认；**App** 负责离车后查看、导航、补拍、弱网。

## 原型入口

- 车机索引：`hmi/hmi-find-index-prototype.html`（00a / 00 / 01）
- 手机示例：`mobile/mobile-uc-find-1-session-prototype.html`
