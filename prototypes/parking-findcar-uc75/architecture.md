# 停车场找车 · HMI 信息架构（UC-FIND-1 / §6.4）

> 与飞书 PRD 对齐：**静态拍照记录车位 + 地图记录点找车**；**不录制**停车过程视频。

## 能力范围

| 有 | 无 |
|----|-----|
| P 挡驻车自动/手动拍照（环视/周视/底盘）；挪车后再拍**覆盖**上一版 | 记忆泊车路径回放 |
| 车机/App 地图记录点、环境照片 | 停车过程视频/连续录像 |
| 第三方地图导航至记录点、弱网快照 | 车机端找车主页 / 步行导航 UI |

## 车机 IVI（1920×1080）— 仅 00 / 01

| 屏 ID | 名称 | 要点 |
|-------|------|------|
| **SCR-FIND-00** | 车位记录 | P 挡采集环视 + 车底环境静态照片 |
| **SCR-FIND-01** | 确认车位 | 预览照片、车位号、重新记录；确认后同步车云 |

**主流程**：00 采集 → 01 确认 → **手机 App** 找车（PG-FIND-01/02 等）。

**采集覆盖**：同一会话内，挪车后再次满足 P 挡零速采集时，新素材与记录点**覆盖**上一版；车机/App 仅保留最新一版（重录同逻辑）。

## 手机 App（390×844）

| 屏 ID | 名称 | 要点 |
|-------|------|------|
| **PG-FIND-00** | 推送落地 | 深链进找车 |
| **PG-FIND-01** | 停车会话卡 | 地图 + 距离 + 环境照片 |
| **PG-FIND-02** | 步行找车 | 指引 + 第三方导航 |
| **PG-FIND-03** | 弱网/分享 | 静态卡、分享粒度 |
| **PG-FIND-04** | 补拍补录 | 离车后补拍 |

**分工**：**车机**负责采集与确认；**App** 负责离车后查看记录点、导航、补拍、弱网。

- 手机示例：`mobile/mobile-uc-find-1-push-prototype.html`
