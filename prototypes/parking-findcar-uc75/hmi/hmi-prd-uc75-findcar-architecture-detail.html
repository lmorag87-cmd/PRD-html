一、行车相机（影像记录）主体架构

PRD 主功能 · 7.1–7.4

对应「启动行车相机 / 主动拍摄与录制 / 紧急视频 / 视频查看与导出」等总览分支：以影像记录应用为入口，经业务策略与视觉服务，完成循环与紧急录制落盘、相册回看及车内外触发。

应用 HMI 策略与开关 视觉服务 编码与叠加 存储介质 触发与联动
Base 1

影像记录应用

首页与预览
  • 四宫格环视预览（二代 8155 等）
  • 前向行车画面（8775 / 8676 等与四宫格可切换）
  • 拍照、录像、设置、回看入口
设置与说明
  • 总开关、录制时长、移除介质、格式化/一键清除
  • 容量查询、录音开关（按平台评估）
状态与提示
  • 状态栏 SD/U 盘图标、空间不足 Toast/对话框
  • 首次启动说明与「不再显示」
Base 2

业务策略

上电与锁车
  • 总开开启：上电车机启动后自动录；锁车下电停录
  • 用户关闭：本次上电不自动录，下次上电恢复自动
与哨兵互斥
  • 哨兵启动后停止行车相机循环录制
介质门槛
  • 未插入 SD/U 盘不可开总开；相关按钮置灰与提示
Base 3

视觉服务

AVM / 环视
  • 四路采集与合成预览（录制与预览同源）
行车前视（若平台支持）
  • 8775 / 8676 等：前视与四宫格同步录制策略
能力边界
  • 近焦、畸变、高速场景体验限制（见 PRD 5.4）
Base 4

编码与时间线

循环与分段
  • 可配置片段时长（如 1/3/5 min），默认与落盘策略
信息叠加
  • 日期时间、行车信号、VIN 等写入画面（PRD 4.4.1）
紧急录制
  • 独立片段、防循环覆盖；与自动/语音/方向盘触发协同
Base 5

存储与相册

SD / U 盘写入
  • 循环视频、紧急视频、照片、哨兵分区（与 PRD 表格一致）
回看与导出
  • 相册 Tab：循环 / 紧急 / 哨兵；全屏播放、倍速、删除、锁定
  • PC 等外设查看与异常断电丢帧上限说明
维护操作
  • 拔出介质前最近文件落盘提示
Base 6

触发与信号

车内触发
  • 语音指令触发紧急录制（冷却策略）
  • 方向盘自定义键触发紧急（冷却 30s 等，以 PRD 为准）
车辆信号（若接入）
  • 碰撞、急刹、ESP、AEB 等自动紧急触发链路
  • IMU 等与紧急策略协同
录音（可选）
  • 舱内与系统音同步、与唤醒/导航等互斥原则
行车相机主链路（摘要） 影像记录 APP：预览 / 拍照 / 录像 / 设置 → 业务策略（总开关、自动录、哨兵互斥、介质校验） → 环视（及支持平台的前视）采集与编码 → 叠加时间与车辆信息，循环或紧急写 SD/U 盘 → 相册回看、删除、锁定、导出；语音/方向盘/车身信号触发紧急支路并行。

二、停车场找车与透明底盘（在主体之上扩展）

UC 7.5 · 共用视觉与存储

在第一节同一套「多路视觉 + 车机存储/相册能力」之上，增加 P 挡车位记录窗口内静态拍照，写入车机本地 media_index；离车前后经蓝牙/数字钥匙将最小停车包推至 App 本地库（§7.5.3 离线可用）。底盘锚点、POI/OCR、定位/地图与车云 App（增强通道，非前置）。不在进场/入库过程中采集找车照片。无透明底盘能力时按 PRD 降级。不录找车长视频，不写入循环/紧急相册。挪车后再采集时，驻车素材与记录点一并覆盖上一版。

人机触发 业务编排 视觉扩展 记录索引 定位地图 车云 App
Ext 1

人机与应用

找车入口（叠加）
  • 桌面卡片 / 停车应用 / 负一屏 / 语音「打开找车」
  • 与影像记录、地图应用跳转关系（UE 定稿）
车位卡片 / 会话 UI
  • 展示驻车记录缩略图（环视/车底等，UE 定稿）
  • POI/OCR 标签（楼层/分区/车位号等）
  • P 挡「车位记录窗口」与手动重录；仅最新一版
Ext 2

车端业务服务

车位记录编排器
  • 会话 ID、与停车事件绑定、置信度与质量提示
  • 驻车段：P 挡零速触发环视/底盘静态照；再采集则覆盖驻车素材与记录点
影像记录业务（共用）
  • 循环/紧急/哨兵策略不变；找车素材命名与索引可扩展字段
Ext 3

视觉域扩展

环视 / 周视（共用）
  • 与第一节同一采集源；找车侧订阅帧或缩略图
透明底盘 / 透视
  • 实时合成流接入车位记录管道
底盘拍照 / 抓拍
  • 用户触发底盘静止帧写入锚点库（找车侧不录短视频）
Ext 4

数据与存储

车位记录素材库
  • media_index：驻车静态照；元数据含 POI/置信度/楼层
  • 车机本地存储；同会话单活跃版本，覆盖时整包替换
SD / U 盘（共用）
  • 介质与配额策略延续第一节；分区策略项目定稿
Ext 5

定位与地图

GNSS / 惯导 / 场端校正
  • 室内地图或记录点降级、POI 文字指引
Ext 6

车云与 App

会话同步与推送
  • 记录点、会话版本、照片元数据；弱网重试
  • 覆盖采集后递增会话版本并同步，App/车机拉取最新版
手机 App
  • 同账号、一键导航、可选同行人分享
扩展主链路（摘要） 找车入口 → 车位记录编排器（P 挡窗口驻车采集；覆盖整包替换） → 环视/周视 + POI 识别 + 透明底盘/底盘拍照 → 车机 media_index → 单活跃版本索引 + 记录点 → 定位与地图呈现 → 车云与 App（仅同步/展示最新版）；与第一节共用存储、账号与合规横切。

横切（两节共用）

数据安全与脱敏、个人信息保护（行车与找车影像同约束）
性能：录制帧率/分辨率基线（4.4.3）+ 找车补充表（4.4.3-1）
诊断：写盘失败、同步失败、合成时延可观测
OTA：能力探测后透明底盘链路降级
