# HMI 信息架构：停车场支付闭环（已对接场站 · F-01～F-12）

## 1. 文档来源与范围

- **飞书 PRD**：[停车场入场—支付—离场](https://baic.feishu.cn/docx/VQX4ddkiboiG4Gxo2V1cAv7DnKf)（token：`VQX4ddkiboiG4Gxo2V1cAv7DnKf`）
- **覆盖终端**：**车机 IVI 为唯一交付界面**（1920×1080）
- **PRD 锚点**：§3 UC-01/02/03；§4 功能清单；§5 M-01～M-06 / F-01～F-12

**场站与支付通道（PRD 口径，禁止「合作停车场」等模糊统称）**

| 概念 | 定义 |
|------|------|
| **已对接场站** | 具备停车识别、计费与闸机授权能力，并与车云/车端完成协议对接的停车场 |
| **ETC** | 通过**已接入的 ETC** 车载单元/路侧能力扣款 |
| **无感支付** | 通过**已接入第三方支付平台的无感停车接口**扣款 |
| **扫码兜底** | 车机展示缴费二维码；车主用**个人手机**上的支付宝/微信等第三方支付 App 完成，**非本 PRD 自有 App 界面** |

**Out of Scope**：手机 App 支付界面、App 内离场导航/Tab、会话只读镜像页等。

**车机负责**

- 入场识别反馈、停车卡片、实时计费与冻结态展示
- 通道探测、自动降级、扫码兜底展示、支付编排与结果
- 悬挂补单、出口闸机不一致强提示、离场引导
- 敏感信息在车机侧的展示与清理

## 2. IVI 壳层与布局（1920×1080）

| 区域 | 视觉 | 职责 |
|------|------|------|
| **状态栏** `status-bar` | 深色 `#1c2128` 类 | 时间、信号、电量；**停车会话轻标**（单色点 +「停车中/待支付/已支付」≤6 字） |
| **主区** `main` | 浅色 `#eceff4` + 白卡片 | 卡片、金额、通道、二维码、引导；正文 **≥18px**，应付金额 **72–96px** |
| **Dock** | 深色，**72–88px** | 左：上下文提示；中：**Home**；右：**屏级主 CTA**（确认支付 / 我已支付 / 完成 / 重试） |

**全局**：安全区 **16px**；触控 **≥48×48px**；字体 **思源黑体族栈**。

**HTML 原型约定**：`hmi/*-prototype.html` **统一不绘制** `#stage` 内左侧栏；跨屏用舞台外 **proto-nav** 索引。

## 5. 关键用户旅程

### UC-01 主路径（车机）

`入场 → SCR-PAY-00 → SCR-PAY-01 → 通道探测 → 支付成功 SCR-PAY-07 → SCR-PAY-11 → SCR-PAY-12`

### UC-02 扫码兜底

`ETC/无感失败 → SCR-PAY-06 展示码 → 车主手机支付宝/微信 → 结果回传车机/车云`

- 车机负责展示码与状态；**不提供**自有 App 收银台原型

### 协同规则

| 主题 | 规则 |
|------|------|
| **Source of Truth** | 场端 + 车云；车机为主操作端 |
| **扫码** | 仅车机 SCR-PAY-06；个人手机第三方支付 App |
| **离场引导** | 仅 SCR-PAY-11 |
